# Trabalho-de-Programa--o---Menu

O Fluxo Diário de Trabalho (Todos usam)

Agora que todos têm o projeto, este será o ciclo de trabalho de vocês:

. Regra de Ouro (Antes de começar a programar): Sempre que abrir o VS Code para trabalhar, clique no botão de Sincronizar (as setas circulares no canto inferior esquerdo) ou digite git pull no terminal. Isso garante que você está pegando as alterações mais recentes que seus colegas enviaram.

. Após fazer alterações no código:
	1. Vá na aba de Controle de Versão (o ícone de Y) no VS Code.
	2. Você verá os arquivos que modificou. Clique no botão + ao lado deles para preparar o envio (Stage).
	3. No campo "Message", digite o que você fez (ex: Adicionei a tela de login).
	4. Clique no botão Commit.
	5. Clique em Sync Changes (Sincronizar alterações) ou Push para enviar para o GitHub.
